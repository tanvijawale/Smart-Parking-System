Smart Parking Management System

The Smart Parking Management System is a C++-based minor project designed to efficiently manage vehicle parking using Object-Oriented Programming (OOP) concepts and C++ STL containers.

The system allows different types of vehicles, including Cars, Bikes, and Trucks, to be registered and automatically assigned to available parking slots. It maintains vehicle information and slot locations, prevents duplicate vehicle registration, and allows users to search for a vehicle using its registration number.

The project demonstrates important OOP concepts such as Abstraction, Inheritance, and Runtime Polymorphism through an abstract Vehicle class and derived classes for different vehicle types. Each vehicle type has its own parking fee, demonstrating polymorphic behavior.

Key Features
Automatic parking slot allocation
Support for Cars, Bikes, and Trucks
Vehicle registration and duplicate checking
Vehicle search using registration number
Parking fee calculation based on vehicle type
Efficient parking data management
Demonstration of OOP and STL concepts
Data Structures Used
Vector – Stores and manages parking slots
Unordered Map – Maps vehicle registration numbers to parking slot numbers
Set – Maintains unique registered vehicle numbers
Technologies Used
C++
Object-Oriented Programming
C++ Standard Template Library (STL)

This project provides a basic implementation of a smart parking system and serves as a practical demonstration of C++ programming, OOP principles, and data structures.
